[b][size=15pt]🔒 Private payments, without elliptic curves[/size][/b]

Monero/Zcash-style curve privacy is a non-starter on a chain built to survive quantum — a quantum computer breaks it, and for confidential amounts it could [i]silently inflate the supply[/i]. So the pool is built on [b]hash-based zk-STARKs[/b]: post-quantum sound, [b]no trusted setup[/b], nothing Shor-breakable.

From the Shield tab:
[list]
[li][b]Shield / unshield[/b] — deposit into the pool, withdraw to a [i]different[/i] address.[/li]
[li][b]Shielded transfers[/b] — note→note payments with [b]no on-chain amount[/b]. A stable [tt]znado…[/tt] shielded address (QR + share), and a [tt]znote…[/tt] claim code you hand the recipient out-of-band.[/li]
[li][b]Any amount + change[/b] — one join-split proof binds ownership (ML-DSA-authorised), Merkle membership in the pool, the nullifier (no double-spend), two output commitments (recipient + change), and value conservation.[/li]
[/list]

The ~1 MB proof stays [b]off L1[/b] — the execution node verifies and applies it, and only the settled pool state-root reaches L1 via the bonded 2/3 quorum.

[hr]

[b][size=15pt]⚡ On-device proving — private [i]and[/i] fast[/size][/b]

Tick [b]"Prove on this device"[/b] and your browser fetches the pool leaves, builds the Merkle path, and generates the entire STARK itself — [b]your keys and amounts never leave the phone[/b]. A browser-made proof is byte-for-byte accepted by the same verifier the node runs.

And it's quick: in-browser proving went from [b]~22 s down to ~2 s[/b] (a WASM BLAKE2b, a WASM Goldilocks field/NTT, a whole-tree WASM Merkle, batch inversion). The exact same Rust binds natively into the node's delegated prover for anyone who'd rather not prove locally. Prefer not to trust your node with the witness? Run your own execution node — or just tick the box.

[b][size=15pt]🛡️ Hardened for the beta[/size][/b]

Before flipping the switch we ran a [b]deep, multi-agent security review[/b] over the whole stack — consensus and rollback, the STARK verifier, the shielded pool, the app contracts, the network/RPC surface, and the Rust cores — then fixed and shipped every real finding. A few of the closes:

[list]
[li]The settlement verifier now [b]pins its own soundness parameters[/b] instead of taking them from the prover.[/li]
[li]A rollback edge that could diverge a snapshot-synced node's state root is closed (it journals the change instead of inferring it from pruned history).[/li]
[li]The app contracts [b]bound every id[/b], closing a cross-entity storage aliasing trick that could lock a table's funds.[/li]
[li]The RPC surface is scoped against oversized-request DoS.[/li]
[li]The post-quantum signature backend now has to [b]prove it rejects bad signatures[/b], not just accept good ones, before the node will adopt it.[/li]
[/list]

Post-quantum ML-DSA-44 authenticates every transaction and block.
